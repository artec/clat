Privacy

隐私政策

最后更新：2026 年 11 月 · 适用于 CLAT 命令行、桌面版、网页工作台与微软商店版

一句话版本。CLAT 本地优先：会话、项目、密钥与设置都保存在你的设备上。没有账户、没有遥测、没有广告，我们也不运营能收集你数据的云端。只有当你配置模型服务商或主动使用需要联网的功能时，数据才会离开你的设备——本产品完全开源，以上每一条都可以在源码里验证。

保存在你设备上的数据

CLAT 记住的关于你的一切，都是 ~/.clat 下的本地文件，不同步、不上传。

  • 会话日志：DSH 兼容的 append-only 对话日志、附件与可重建的本地检索缓存
  • 凭证：各厂商模型 API 密钥保存在 ~/.clat/credentials.json（0600 权限），配额控制台授权在本机加密存储
  • 项目知识：记忆、目标、项目信任决策与插件写授权记录
  • 扩展：已安装插件包及其签名与回滚记录

退出 CLAT 后删除 ~/.clat 即可一次清空。卸载程序不会动这个目录，删不删由你决定。

CLAT 绝不做的事

  • 不注册账户，不建立 CLAT 运营的用户画像
  • 不内置遥测、统计或崩溃上报
  • 不投放广告，不集成任何追踪 SDK
  • 不出售、不共享数据——对话内容不经过我们运营的服务器

什么数据会离开设备——仅在你使用时

以下功能默认全部关闭，只有你配置或主动调用时才会发起网络请求。与所有 HTTPS 流量一样，接收方会看到请求的来源 IP。

模型服务商

发送提示词时，指令本身、智能体读取的项目文件内容、附带的图片、工具输出与所需上下文，都会发送给你选定的模型服务——直连厂商（DeepSeek、GLM、Qwen、Kimi、腾讯），或 OpenCode Go 这类聚合多家厂商模型的网关渠道。API 密钥只发送给对应服务、仅用于鉴权；内容按该服务自己的隐私政策处理。

插件市场

浏览、搜索或安装 pi.at.cn 插件市场里的插件时，搜索词与安装请求会到达本项目运营的市场服务，我们只保留维持服务所需的技术日志。安装包在激活前会先在你的设备上完成签名校验。

更新检查

clat upgrade --check 与桌面版更新只会向 GitHub Releases 请求签名的版本清单（latest.json）。

网页搜索与抓取

内置 web_search / web_fetch 会把搜索词或目标 URL 发给你配置的搜索后端：配置了密钥走 DeepSeek 搜索 API，无密钥配置则走本项目运营的共享搜索服务。直接 HTTP 抓取在你的机器上完成。

控制台配额授权

配额指标可以连接你的服务商控制台，展示你自己的用量与余额。每次授权都由你主动发起，凭证保存在本机，且只用于读取用量数字：

  • 通义千问平台——通过平台设备流登录：在浏览器里确认授权，得到的凭证在本机静态加密存储（内嵌密钥，模型 API 密钥全程不参与）
  • 阿里云百炼——浏览器回调到本机的一个本地监听端口，把控制台访问令牌交给 CLAT；监听只在登录期间存在（取消登录立即关闭），之后到达的回调不会被存储
  • 腾讯混元——保存腾讯云 API 密钥，仅用于对腾讯云接口发起 TC3 签名的配额读取

授权在同一宿主上的各项目间共享，随时可在「设置 → 授权」中查看或删除；删除即清除已保存的凭证。

微信远程

仅当你以 clat serve --im wechat 启动时：你通过微信收发的消息、图片与审批会经过腾讯的消息基础设施，受腾讯隐私政策约束。

外部智能体与扩展

你委托给 ACP 外部智能体的任务由你自行安装并信任的本机软件执行，任务内容与结果遵循该智能体及其模型服务商自己的政策。你安装的 MCP 服务器与插件同理：它们是你选择运行的第三方软件，其自身的网络行为与隐私政策适用。

CLAT 可能申请的系统权限

  • 文件访问仅限你打开的项目与明确授权的目录
  • 应用操作（macOS 辅助功能、Windows UI 自动化）在本地读取界面树；敏感控件每次单独确认，决策可在 /ui-consents 复查
  • 非完全访问模式下，命令运行在系统沙箱约束下（macOS Seatbelt、Windows 受限令牌）
  • 本地工作台 clat serve 默认只监听 127.0.0.1；远程访问需要凭证，会话使用 HttpOnly Cookie，凭证绝不出现在 URL 中

第三方服务

模型内容由你选择的服务处理——DeepSeek、GLM（智谱）、Qwen（阿里）、Kimi（月之暗面）、腾讯混元等直连厂商，或 OpenCode Go（opencode.ai）这类聚合多家厂商模型的网关渠道（其工作区另有数据驻留区域设置）——并适用该服务的隐私政策。版本下载与更新清单来自 GitHub；微信消息经腾讯基础设施传输。插件市场（pi.at.cn）与无密钥共享搜索服务由本项目运营，只保留维持服务所需的技术日志。

关于本政策

  • 适用范围——CLAT 命令行、桌面版、网页工作台与微软商店版
  • 未成年人——CLAT 是开发者工具，不面向未成年人
  • 政策变更——随产品演进可能更新本页，以上方日期为准
  • 联系方式——在 github.com/artec/clat/issues 提交 issue
