Why CLAT

命令行 + 工具 + 模型

CLAT 把模型接入你的终端：读代码、改文件、跑命令都在本地完成，每一步操作可见、可控、可审计。

本地优先

会话以 append-only 日志落盘，配置、密钥与信任状态存本地 JSON 文件（~/.clat）。没有云端依赖，数据不出你的机器。

单二进制

Rust 编译的单文件可执行程序，无运行时、无依赖安装。macOS、Linux 与 Windows 六个平台开箱即用。

安全默认

进入新目录先过信任门；权限分只读、项目写入、完全访问三档可切换，默认档位下写文件、执行命令逐次询问，路径不出项目根。

Positioning

同一容器血统，三条路线

Spring、DeepSeek Harness 与 CLAT 共享同一个「组装式容器」的器官——把系统拆成可声明、可组合的部件（这一思想可上溯到 IoC 与 OSGi 运动）——却服务不同的用户、走向不同的方向。下表帮第一次接触 CLAT 的你快速定位。

SpringDSHCLAT
定位企业级 Java 应用框架「一切皆插件」的 Agent 运行时稳如磐石的 Agent 底座
用户构建应用的程序员驱动 agent 的开发者与模型自身追求本地优先、单二进制、可审计的用户
容器哲学让程序员忘记容器的存在让运行时随时可改写让用户能够审计容器
组合时机编译期 / 部署期运行期编译期（静态清单），扩展经 MCP 外移
扩展方式jar + 接口进程内 TypeScript 插件MCP 协议 + 门控 WASM

Spring 让程序员忘记容器，DeepSeek Harness 让模型改写容器，CLAT 让用户审计容器。如果你想要的是一个稳、小、看得见的 Agent 底座——那就是这里。

Features

为真实编程工作流设计

01 — 模型

模型厂商开箱即用

DeepSeek、GLM、Qwen、Kimi 官方预设内置，任意 OpenAI 兼容端点同样能用。/model 打开两级选择器：先选厂商，再选模型，密钥按厂商分槽保存。

02 — 输入

图片附件与输入召回

把本地图片拖进终端即成为会话附件，随消息一起发送给视觉模型；输入历史支持 ↑/↓ 召回，按项目隔离。

03 — 交互

交互式询问与会话转向

模型遇到该由你拍板的事会停下来提问；运行中也能随时插入转向消息，改变当前任务的方向。

04 — 运行

无限制轮次与自动压缩

轮次没有上限，任务跑完为止；上下文用到八成自动压缩摘要，原始历史完整保留。

05 — 权限

三档权限模式

只读、项目写入（默认）、完全访问三档随时切换：/perm 或权限弹窗内一键换档、可临时提权，按项目记忆。低两档下写文件、跑命令仍逐次审批。

06 — 集成

MCP 原生

MCP 服务器支持 stdio 与 Streamable HTTP 远程传输；GLM Coding Plan 自动挂载官方四台 MCP 服务器，/mcp 查看连接状态与已注册工具。

07 — 遥测

状态栏实时反馈

DeepSeek 余额、GLM 5 小时窗口额度、Kimi 额度、KV 缓存命中百分比、上下文占用与思考强度常驻底部；统计从会话日志还原，重启不归零。

08 — 持久化

崩溃安全的会话持久化

完整对话写入 append-only 日志，先落盘再调用模型，崩溃后自动恢复到最近的完整批次；日志为 DSH 兼容格式，可被兼容工具直接读取。模型自动起标题，/rename 随时改。

09 — 升级

自更新

clat upgrade 从 GitHub Releases 拉取当前平台的最新二进制并原子替换自身，一条命令升级。

10 — 插件

WASM 插件

与 DSH 插件生态互通：社区现成的能力拿来即用，你写的插件两边通用。稳定的 Rust 底座配上开放的插件生态，把 CLAT 组合成你需要的 Agent 系统。

11 — 生态

DSH 宿主客户端

一条 clat dsh 连上本地 DSH 宿主，CLAT 界面就成为它的终端：DSH 的会话、提问与审批都在同一套 TUI 里完成，断线自动重连；对 ~/.dsh 只读不写，一切经官方 API 交互。

12 — 前端

Web 客户端与本地 API

clat serve 在本机启动一个 HTTP+SSE 服务，浏览器打开即是可安装的 Web 客户端（PWA）；clat exec --json 把全部运行事件以 NDJSON 输出，供编辑器与流水线消费。

Get started

安装

推荐用一键脚本：自动识别平台、下载 Release 二进制、验证 Minisign 签名与 SHA-256 后放入 ~/.local/bin（Windows 为 %LOCALAPPDATA%\Programs\clat）。预装校验需要 minisign（macOS：brew install minisign）；没有预编译产物时回退到源码构建。

一键脚本（推荐）

macOS / Linux

❯curl -fsSL https://raw.githubusercontent.com/artec/clat/main/install.sh | sh

脚本会提示把 ~/.local/bin 加入 PATH

Windows PowerShell

❯irm https://raw.githubusercontent.com/artec/clat/main/install.ps1 | iex

自动安装到 %LOCALAPPDATA%\Programs\clat

手动下载

也可以从 Releases 页面下载对应平台的二进制，放入 PATH 即可。已安装用户用 clat upgrade 自更新。

平台资产架构

macOSclat-v*-x86_64-apple-darwin.tar.gzIntel

Windowsclat-v*-x86_64-pc-windows-msvc.zipx64

Linux 产物要求 glibc 2.39+（Ubuntu 24.04 同代及以上），更老的发行版请从源码构建。解压后先 clat --help 看一眼，进入项目目录运行 clat，首次会请求信任该目录。脚本安装同理，装完直接运行 clat 即可。
