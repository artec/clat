Why CLAT

命令行 + 工具 + 模型

CLAT 把模型接入你的终端：读代码、改文件、跑命令都在本地完成，每一步操作可见、可控、可审计。

本地优先

会话、输入历史、模型配置全部存在本地 SQLite（~/.clat）。没有云端依赖，数据不出你的机器。

单二进制

Rust 编译的单文件可执行程序，无运行时、无依赖安装。macOS 与 Windows 四个平台开箱即用。

安全默认

进入新目录先过信任门；写文件、执行命令逐次询问；路径访问限制在项目根内，杜绝越界。

Features

为真实编程工作流设计

双厂商开箱即用

DeepSeek 与 GLM Coding Plan 官方预设内置。/model 打开两级选择器：先选厂商，再选模型，密钥按厂商分槽保存。

状态栏实时反馈

余额（DeepSeek）、5 小时窗口剩余额度（GLM）、KV 缓存命中百分比与思考强度常驻底部状态栏，成本一目了然。

会话持久化

断点续聊：完整工具上下文按会话存档，重启后接着上次的进度继续。输入历史支持 ↑/↓ 召回，按项目隔离。

自更新

clat upgrade 从 GitHub Releases 拉取当前平台的最新二进制并原子替换自身，一条命令升级。

Get started

安装

推荐用一键脚本：自动识别平台、下载 Release 二进制、验证 Minisign 签名与 SHA-256 后放入 ~/.local/bin（Windows 为 %LOCALAPPDATA%\Programs\clat）。预装校验需要 minisign（macOS：brew install minisign）；没有预编译产物时回退到源码构建。

一键脚本（推荐）

❯curl -fsSL https://raw.githubusercontent.com/artec/clat/main/install.sh | sh

macOS / Linux — 脚本会提示把 ~/.local/bin 加入 PATH

❯irm https://raw.githubusercontent.com/artec/clat/main/install.ps1 | iex

Windows PowerShell

手动下载

也可以从 Releases 页面下载对应平台的二进制，放入 PATH 即可。已安装用户用 clat upgrade 自更新。

平台资产架构
macOSclat-v*-aarch64-apple-darwin.tar.gzApple Silicon
macOSclat-v*-x86_64-apple-darwin.tar.gzIntel
Linuxclat-v*-x86_64-unknown-linux-gnu.tar.gzx64
Linuxclat-v*-aarch64-unknown-linux-gnu.tar.gzARM64
Windowsclat-v*-x86_64-pc-windows-msvc.zipx64
Windowsclat-v*-aarch64-pc-windows-msvc.zipARM64

Linux 产物要求 glibc 2.39+（Ubuntu 24.04 同代及以上），更老的发行版请从源码构建。解压后先 clat --help 看一眼，进入项目目录运行 clat，首次会请求信任该目录。脚本安装同理，装完直接运行 clat 即可。
