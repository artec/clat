# DSH 版本对齐与源码对照

按本次交付选流程。

- **版本升级或兼容问题**。跟进 DSH 发布、规划具体兼容批次、修复会话互读或实现格式迁移时，读[版本升级手册](references/session-upgrade-playbook.md)。正式升级分别核对会话格式、事件词汇、网关和写入锁协议。单点问题按受影响的契约验证。
- **产品机制或架构对照**。用户明确要求依据 DSH 实现作设计判断时，记录用于比较的 DSH revision，查对应实现、测试和 CLAT 当前行为。列出双方行为与约束，按具体需求决定采用、适配或保留现状，并给出对应的验证方法。涉及会话、网关或写入锁契约时，查版本升级手册中对应章节。其他接口按其自身互通要求验证。
- **外观与交互参考**。以 DSH 为界面或操作体验参照时，按普通产品设计流程处理。

设计对照示例。研究提示词和压缩时，比较快照由谁生成、何时刷新、是否进入持久历史，以及压缩和恢复如何处理。只有涉及会话互读的改动才需要对应的跨读验证。请求字节稳定性和供应商缓存命中率分别取证。
